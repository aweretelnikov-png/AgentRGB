# План отдельного опыта 03H

Статус: пользователь разрешил опыт 2026-09-21. Скрипт `stop_once.py` подключается только к отдельному экспериментальному процессу.

1. Запустить отдельный `codex exec --ephemeral` в экспериментальном каталоге с read-only sandbox.
2. Подключить регистратор и один временный Stop hook только аргументами `-c` этого процесса. Пользовательский `config.toml`, trust store и проектную `.codex/` не менять.
3. На первом Stop вернуть `decision: block` с фиксированным указанием ответить «OK» без инструментов и чтения файлов. На повторном Stop вернуть пустой stdout. Использовать одновременно `stop_hook_active` и локальный одноразовый маркер, чтобы исключить цикл даже при неожиданной семантике флага.
4. Сохранить только разрешённые поля двух Stop и сопутствующих событий; сравнить `session_id`, `turn_id` и `stop_hook_active`.
5. Завершить тестовый процесс; hook останется только как неподключённый материал опыта в `experiments/codex-events/`.

Ожидаемое воздействие — ровно один дополнительный короткий модельный ход. Опыт не меняет решения об одобрении инструментов. Одноразовый флаг доверия hooks допустим только после проверки, что кроме созданных для опыта обработчиков нет других активных hooks; sandbox и approvals остаются включёнными.

Основание отдельного согласования: раздел 03H пользовательского задания прямо требует показать план и получить разрешение перед добавлением изменяющего Stop hook.
