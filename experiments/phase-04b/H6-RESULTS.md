# H6: graceful shutdown production Direct Mode — успешный физический опыт

23 сентября 2026 года пользователь отдельно разрешил один H6, подтвердил
Wired mode и визуально видимую исходную статичную разноцветную подсветку.
Использованы настоящий `EventServer` на `127.0.0.1:8765`, `Core` и production
`AulaF75Output`. Синтетический `run_started` принят через обычный HTTP endpoint
со статусом `200`; Pi-процесс не запускался. После примерно 3,5 секунд blue
heartbeat таймер инициировал `KeyboardInterrupt` через
`_thread.interrupt_main()`. Main loop поймал его тем же обработчиком, что
используется для Ctrl+C; затем штатный `EventServer.server_close()` вызвал
`Core.close()` и release production-адаптера. Прямого вызова `release()` из
сценария не было.

[Машинный журнал](results/production-h6-20260923T180436410810Z/summary.json)
и [визуальное подтверждение](results/production-h6-20260923T180436410810Z/visual-confirmation.json)
сохранены отдельно. Fresh identity gate перед первым кадром подтвердил
`258A:010C`, `MI_01/COL06`, usage `FF00/0001`, feature length 520,
объявленный report ID `06`, model `03`, PSD `00CD`. Единственный read-only
`0x82` ответ имел SHA-256
`40d4fc0f4a1091627643a59dfbfd42eab89749b55c6ea15031e04a8703196523`.

Отправлено **57** одинаковых Direct-кадров `0x06/0x08`, все API-вызовы
успешны; пределы 100 кадров и 5 секунд не достигнуты. Активный Direct Mode
продолжался **3,539 с**; кадры отправлял один worker. Запрещённые
`0x04`, `0x0A`, `0x39`, `0x3C`, disable и restore не отправлялись.

Последний кадр уже выполнялся при отправке программного сигнала. Он
завершился **до получения `KeyboardInterrupt` и до stop worker**. После stop
новых кадров **0**. Последняя запись предшествовала завершению worker и
закрытию handle. Watchdog не сработал; процесс завершился с кодом `0`.
После выхода независимая проверка не обнаружила listener на `8765`.

Пользователь подтвердил одноцветный синий во время heartbeat и
самостоятельный возврат исходной статичной разноцветной подсветки через
несколько секунд без power cycle. После shutdown дополнительных HID-команд,
в том числе read-only, не отправляли.

**Итог:** H6 полностью прошёл в пределах одного физического опыта.
Штатный cleanup при `KeyboardInterrupt` освобождает worker, HID handle и
listener без restore-записей. H7 (controlled heartbeat failure), Pi и 04C
не запускались; commit не делался.
