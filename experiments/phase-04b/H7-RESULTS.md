# H7: controlled heartbeat failure — успешный физический опыт

23 сентября 2026 года пользователь отдельно разрешил один H7 и подтвердил
Wired mode, исходную статичную разноцветную подсветку и готовность наблюдать
синий. Использованы настоящий `EventServer` на `127.0.0.1:8765`, `Core` и
production `AulaF75Output` с тестовым наследником. Наследник внедрил
`RuntimeError("h7_controlled_software_fault")` через приватный
`_after_direct_frame()` **после 20-го успешного кадра**. Windows HID backend,
`HidD_SetFeature` и USB не подменялись и не отключались.

[Машинный журнал](results/production-h7-20260923T182354144532Z/summary.json),
[raw `0x82`](results/production-h7-20260923T182354144532Z/model-82.bin) и
[визуальное подтверждение](results/production-h7-20260923T182354144532Z/visual-confirmation.json)
сохранены отдельно. Fresh production identity gate непосредственно перед
первым кадром подтвердил `258A:010C`, `MI_01/COL06`, usage `FF00/0001`,
feature length 520, объявленный report ID `06`, model `03`, PSD `00CD`.
SHA-256 полного ответа `0x82`:
`40d4fc0f4a1091627643a59dfbfd42eab89749b55c6ea15031e04a8703196523`.
Read-only `0x82` запрос был один, без retry.

Было **20 попыток и 20 успешных** Direct-кадров `0x06/0x08`, все uniform blue,
через одного worker. Активная длительность **1,275 с** при пределах 3 с и
60 кадров. Никакие `0x04`, `0x0A`, `0x39`, `0x3C`, disable или restore не
отправлялись. Изменяющих записей после fault — **0**; попыток reopen и
retry — **0**.

После fault адаптер выставил `heartbeat_failed`, остановил worker и закрыл
handle. Пока Core и listener оставались живыми, HTTP `run_waiting` и
`run_resumed` того же run получили `200`; новый handle не открывался и новый
worker не создавал кадров. Затем runner штатно закрыл сервер и Core.
Независимая проверка после завершения подтвердила отсутствие listener на
`8765`. Непредвиденных исключений runner не было.

Пользователь подтвердил визуально одноцветный синий во время heartbeat и
самостоятельный возврат исходной статичной разноцветной подсветки через
несколько секунд без power cycle. После H7 никаких дополнительных
аппаратных команд не отправляли.

**Итог:** физический H7 прошёл полностью. Ошибка программного слоя после
успешных Direct-кадров не остановила Core, но безопасно прекратила аппаратный
output; пользовательский профиль вернулся без restore. Pi и 04C не запускались,
commit не делался.
