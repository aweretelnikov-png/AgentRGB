# H5: production Direct Mode — успешный физический цикл

23 сентября 2026 года пользователь отдельно разрешил один H5 и подтвердил
перед запуском Wired mode и визуально видимую
`исходную статичную разноцветную подсветку`.
Использован существующий production `AulaF75Output` через ограниченный
`production_h5.py`; H6/H7, Pi и 04C не запускались.

[Машинный журнал](results/production-h5-20260923T175153833618Z/summary.json)
и [визуальное подтверждение](results/production-h5-20260923T175153833618Z/visual-confirmation.json)
сохранены отдельно. Fresh identity gate непосредственно перед первым кадром
подтвердил `258A:010C`, `MI_01/COL06`, `FF00/0001`, feature length 520,
объявленный ID `06`, model `03`, PSD `00CD`. Единственный read-only цикл
`0x82` дал SHA-256 полного ответа
`40d4fc0f4a1091627643a59dfbfd42eab89749b55c6ea15031e04a8703196523`.

| Core state | Direct RGB | Успешных кадров | Визуально |
|---|---|---:|---|
| `working` | `0000FF` | 47 | синий |
| `waiting` | `FFFF00` | 47 | жёлтый |
| `working` | `0000FF` | 49 | снова синий |
| `completed` | `00FF00` | 33 | зелёный |
| `idle` | нет кадров | 0 | исходный профиль вернулся сам |

Всего **176 Direct-кадров из 240 разрешённых**, все 176 вызовов Windows API
завершились успешно. Один worker отправлял кадры; активная длительность
**11,051 с** при пределе 12 с. После `idle` worker остановился, handle закрыт,
ошибок нет. Экспериментальный budget/allowlist пропускал только read-only
`0x82` и подтверждённые Direct-кадры `0x06/0x08`; `0x04`, `0x0A`, `0x39`,
`0x3C`, disable и restore не отправлялись. После `idle` вообще не отправляли
новых HID-команд, включая read-only.

Пользователь подтвердил всю визуальную последовательность и самостоятельный
возврат исходной статичной разноцветной подсветки через несколько секунд
после зелёного. Точное время аппаратного timeout не измерялось.

**Итог:** H5 полностью прошёл в пределах одного физического опыта. Обычный
production state rendering и release через прекращение volatile heartbeat
подтверждены на данной F75. Это не заменяет отдельной проверки graceful
shutdown H6 и controlled heartbeat failure H7. Ни H6, ни H7 автоматически
не запускались; commit не делался.
