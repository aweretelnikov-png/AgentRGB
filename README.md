# AgentRGB

AgentRGB — открытая локальная система физической индикации состояния ИИ-агентов через RGB-периферию компьютера.

Общий поток данных:

```text
ИИ-агент → события источника → нормализованные события AgentRGB
         → состояние сеансов и временные сигналы
         → правила индикации → адаптер вывода → RGB-устройство
```

Проект отделяет источники событий от способов вывода. Ядро не должно знать о Codex, Pi, OpenRGB или конкретной клавиатуре. В первой версии планируются источники Codex и Pi coding agent, а первым выходом станет прямой HID-адаптер AULA F75 по USB. OpenRGB остаётся будущим универсальным выходом для совместимых устройств.

AgentRGB работает локально на Windows, не требует учётной записи или облачного сервиса и не должен передавать наружу содержимое запросов и ответов модели.

## Состояние проекта

Проект находится на этапе проектирования и технических экспериментов. Производственный код, зависимости, конфигурация сборки и реализации интеграций ещё не созданы; каталог `experiments/` содержит только воспроизводимые исследовательские прототипы и их результаты.

## Статус интеграций

Точные события внешних систем и возможности выходных адаптеров должны быть подтверждены техническими прототипами. Для AULA F75 подтверждено прямое чтение и ограниченное изменение RGB-профиля, но не полная семантика профиля и не побайтное аппаратное восстановление. Документация явно отделяет подтверждённые факты от проектных предположений.
